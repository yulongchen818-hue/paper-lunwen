# 08_public_data_protocol

Public datasets that stand in for each data class the system ingests, so that ingestion behaviour can be
re-executed without project data.

| Dataset | Identifier | Licence | Included here |
|---|---|---|---|
| UCI Steel Plates Faults | doi:10.24432/C5J88N | CC BY 4.0 | yes (`UCI_steel_plates_faults.zip`, 1,941 records, 27 features, 7 classes) |
| Cracks in Steel Bridges (CSB) | doi:10.4121/6162a9b6-2a20-4600-8207-e9dcd53a264a.v2 | CC BY-NC-ND 4.0 | no (licence forbids redistribution) |
| GDXray weld radiography | repository documentation | research and education only | no |
| Laboratory bridge acceleration data | doi:10.17632/np8fvycwnx.1 | CC BY 4.0 | no (size; download from the identifier) |
| NYSDOT bridge conditions | https://data.ny.gov/d/wpyb-cjy8 | public domain | 25-record sample (`NYSDOT_bridge_conditions_sample25.json`) |
| FHWA Bridge Welding Reference Manual (FHWA-HIF-19-088) and Inspector's Checklist | agency publications | public domain | checklist as Markdown (24 items) |

Schedule-task extraction is not covered by the protocol; no public construction programme with a citable
dataset identifier was found.
